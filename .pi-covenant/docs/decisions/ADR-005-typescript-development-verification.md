# TypeScript local verification

Replace Python contract/probe scripts with typed TypeScript, Effect scoped process execution, native JSON evidence and explicit failure policies. pnpm check is canonical; the shell bootstrap delegates to it. Timeouts, missing commands, partial diagnostics, stale inputs and incomplete steps cannot pass. Fallow rules are generated from declared module dependencies and checked for drift; compiler-based import checks enforce public module ports.

Seven architecture faults and a real Fallow forbidden-import probe exercise the policies. Existing worktree fault probes remain separate. Prior ADR command examples describe their historical setup and are superseded here. CI is deferred.
